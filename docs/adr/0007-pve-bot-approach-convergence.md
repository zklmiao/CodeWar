# ADR-0007：PvE Bot 超距接近的收敛语义

**状态**：已接受（19 号票，2026-10-24，架构师对 19 号票裁决 1 字面与裁决 4 场景
冲突的裁定：认可"跨回合最大进度"读法）。
**关联**：19 号票；ADR-0005（PvE Bot 边界）；设计 003 §2（射程表）、§5（反风筝注记）

## 背景

19 号票修复"Bot 随机移动走出攻击射程后攻击永久 miss（dodged=true）空转到回合
上限"。裁决 1 的字面：超距回合的移动目标选"移动后距离落入射程内"的合法格，
找不到才退回随机移动。但存在**一步进不了射程**的局面——裁决 4 要求的回归场景
本身就是：Bot(0,0)/对手(4,4)，曼哈顿距离 8，游侠射程 3、移动上限 3，走一步
最好剩距离 5。按字面读法，此时"移动后落入射程内的合法格"不存在 → 退回随机
移动 → Bot 无法确定性收敛，缺陷换皮复活，19 号票验收 2 无法满足。

两个候选读法冲突，呈报架构师；架构师裁定：认可"跨回合最大进度"读法。

## 决策

**超距接近是跨回合目标，不限于单步可达。** 具体为三层取法（`bot.ApproachMove`）：

1. 存在"移动后距离 ≤ 射程"的合法落点 → 取步数最小的一个：停在射程边缘，
   不贴脸（保持设计 003 §5 的走位博弈语义）。
2. 一步够不着射程 → 沿主轴（|Δrow| ≥ |Δcol| 取行轴，与引擎自动瞄准同构）取
   "移动后距离最小"的合法落点做最大进度（同距取较小步数，不越过对手），
   跨回合收敛进射程。
3. 仅当主轴被彻底封死（无任何合法落点）→ 退回现行随机移动（裁决 1 的退化
   分支，不 panic、不出错占位）。

配套口径：距离量纲 = 曼哈顿（裁决 2）；射程 = max(普攻射程, 就绪技能射程)
（剑士 1 / 法师 2 / 游侠 3，穿云箭就绪放大到 4，治疗/邻域技能不放大）；
接近落点的合法性规则以 `LegalMoves`（引擎 validateMove 同语义）为单一来源；
引擎与自动瞄准钳制 `min(射程, 距离)` 零改动——超距攻击落空是玩家侧走位博弈
的正确语义，修复只在 Bot 决策层。

## 后果

- **(+)** 超距 Bot 确定性收敛进射程，消除"随机游走不收敛 → 永久 miss 空转"。
- **(+)** 一步可进射程时与裁决 1 字面完全一致；封死退化分支保留且有纯函数
  负例钉住（数学上 d>reach≥1 时主轴 step-1 恒合法，生产不可达，属防御性代码）。
- **(−)** 曼哈顿量纲的已知代价：斜向贴脸时 burst8 实际可命中但剑士会多走一步
  （保守方向，不会 miss）；法师线扫对斜向目标"判在射程内"但直线覆盖落空。
  属 spec 走位博弈语义，本 ADR 不处理。
- **(−)** 接近回合跳过 `PickMove` 的随机抽取，随机流自首个接近回合起偏移
  （19 号票提交信息已说明，既有种子测试全绿确认不破）。

## 备选方案（被否原因）

- **严格字面（一步够不着 → 随机移动）**：(0,0)/(4,4) 回归场景不收敛，验收 2
  无法满足，缺陷复活——架构师否决。
- **距离>射程时改行动权重、强制接近行动**：改变行动分布与难度行为轮廓
  （权重表是 spec 开放问题 3 的调参面，19 号票明令不动），且违背裁决 1
  "射程内时维持现行权重决策"的边界——未采用。
