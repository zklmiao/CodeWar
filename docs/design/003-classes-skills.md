# 设计 003：职业与技能表（MVP 三职业）

> 依据：Spec 001 + 三项已确认决策（数值小幅开放 / 严格双系：伤害·治疗 / 冷却按强度浮动 2-4 回合）。
> 本表数值为**初稿**：实现按表执行；playtest 调参后修订本表（表格是数值唯一权威，代码不硬编码平衡值之外的新数值）。

## 1. 全局规则（本设计细化，与 Spec 兼容）

- **方向选择**：所有线性覆盖（普攻与技能）在结算时由攻击者选定一个正交方向，命中该方向上的覆盖格——Spec 的"形状=相对攻击者的格子偏移集合"按此落地。方向选择是结算界面上的免费操作，不消耗答题。
- **空挥规则**：结算时目标不在覆盖格内 = 本次攻击无效（闪避的镜像面）。近战职业的风险面即由此产生。
- **治疗不得溢出**：治疗不能超过最大 HP；治疗速率上限（见 §4）保证伤害最终获胜。
- **盲选职业**：1v1 匹配双方同时锁定职业、互不可见（防 counter-pick）。合作模式再考虑可见协商。

## 5. 平衡注记（速算，时间系数取均值 0.8、难度系数 1.0）

- **期望轮伤**：剑士 20.8（需贴脸）/ 法师 14.4（线扫）/ 游侠 16（点狙）。击杀所需命中次数：剑士→法师 5 发、法师→剑士 8 发、游侠→剑士 7 发、剑士→游侠 5 发。
- **反风筝机制是棋盘本身**：5×5 有界 + 每回合单行动——游侠移动的回合不出伤害，剑士追击的回合不吃伤害；角落封路后距离必然崩塌。不需要额外反风筝规则。
- **治疗天花板**：全部治疗包折算 ≤14 轮伤/回合，低于最低期望轮伤 14.4——伤害最终获胜，龟缩治疗无法无赖化。⚠️ playtest 旗帜：当攻击方时间系数打满 0.6 下限时（轮伤 10.8），游侠风行回复（14/回合）可形成僵局，靠超时按剩余 HP 裁决；若实测出现，优先上调时间系数下限而非砍治疗。
- **相性叙事**：剑士克法师（追得上、扛得住）；游侠克剑士（放风筝、换血赚）；法师克游侠（线扫惩罚站在线上的走位）——三角闭环，对称博弈有解。
- 超时裁决、同时归零平局、ELO 平局 +0 均沿用 Spec，不在本表重复。
