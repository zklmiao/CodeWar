# 13: 美术占位规范

**What to build:** 统一的占位视觉系统，让 MVP 全程使用一致性占位资产、正式美术日后可整包替换：色板与设计 token（CSS 变量单一来源）、字体层级与间距、网格/角色（3 职业可区分）/血条/题卡/技能槽/结算面板等占位组件、资产命名约定；一个风格页（style guide page）展示全部占位组件。后续界面票据采用本规范的占位资产，不再出现各写各的临时配色。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 风格页展示全部占位组件（网格、3 职业角色、血条、题卡、技能槽、结算面板）
- [ ] 设计 token（色板/字体/间距）有单一来源并被界面引用
- [ ] 占位资产命名约定文档化，支持整包替换为正式美术
- [ ] 3 职业占位形象在占位层面即可区分（剪影/主色差异）
