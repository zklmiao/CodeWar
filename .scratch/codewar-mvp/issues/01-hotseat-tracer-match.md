# 01: Tracer——热座最小对局

**What to build:** 同屏热座 1v1 最小可玩对局：两名玩家在同一浏览器各控一个角色，每回合题面板展示一道攻击题（硬编码的补全函数题），75 秒倒计时内作答。全部测试用例通过行动才生效；错误提交锁定 5 秒并自损 3 HP；回合结束按完成耗时排序结算攻击，伤害 = 基础 22 × 时间系数（0.6~1.0，越快越高）；HP 归零判负、双方同时归零平局、总时长耗尽按剩余 HP 判定。同时落地 CI 与 MatchEngine 对局事件流断言测试基建——这是全部后续票据的地基。技术栈与同步模型已由 docs/adr/0001 与 0002 预先决议，本票按 ADR 落地脚手架。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 两名玩家可在同一浏览器完成一整局并分出胜负（含平局与超时判定路径）
- [ ] 回合倒计时、错误锁定 + 自损、全对生效的行为与 spec 数值初稿一致
- [ ] 结算顺序 = 完成耗时顺序；同题竞速耗时越短伤害越高（时间系数生效）
- [ ] 对局事件流断言覆盖：结算顺序、错误惩罚、平局、超时（错误路径优先）
- [ ] 脚手架遵循 ADR-0001：monorepo 布局（client/server/judge/proto/db/deploy）就位，Compose 三服务可启动，CI 全绿
