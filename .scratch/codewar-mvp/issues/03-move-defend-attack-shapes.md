# 03: 移动与防御动作 + 攻击形状与走位闪避

**What to build:** 热座对局从"只有攻击"扩展为三动作：每回合题面板同时展示 攻击题（双方镜像同实例）/ 移动题 / 防御题（后两者双方私有实例），玩家一回合只能选一道作答。解出移动题在 5×5 网格移动 1-2 格（正交方向）；解出防御题本回合获得 60% 减伤；攻击带形状（普攻=相邻格直线），结算时按 defender 的结算位置判定命中——不在攻击形状覆盖格内即闪避成功。移动与防御从此成为有战术意义的硬动作。

**Blocked by:** 01 (Tracer——热座最小对局)

**Status:** ready-for-agent

- [ ] 三槽面板可各自作答并执行对应行动；一回合仅一题生效（一个行动）
- [ ] 攻击题为镜像同实例；移动/防御题为双方私有实例
- [ ] 走位移出攻击形状覆盖格 → 事件流记录闪避、无伤害
- [ ] 防御成功时该回合所受伤害乘 0.4（−60%）
- [ ] 事件流断言覆盖错误路径：移入攻击覆盖格仍被命中、防御与闪避同时存在时的结算顺序
